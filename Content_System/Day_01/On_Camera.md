# On-Camera Dialogue Guide

**Dialogue**: 
"I have exactly 90 days to learn Data Science from scratch, or I’ll be stuck in my current career forever."
*(Cut to B-Roll)*
"Today is Day 1. [Slight smile] The mission? Python basics. Opening VS Code for the first time was super intimidating. [Look down slightly, then back to camera]. But I started small. Variables, basic math, and finally getting my first line of code to actually work. [Small triumphant smile]. It’s a tiny win, but I'll take it. Tomorrow, we tackle loops. Wish me luck."

**Performance Notes**:
- Emotion: Determined and slightly anxious.
- Eye Contact: Maintain strong eye contact during the hook and the ending.
- Pauses: Let the realizations breathe. Don't rush the words.

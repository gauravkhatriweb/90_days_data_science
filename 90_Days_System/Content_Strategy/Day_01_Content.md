# Day 1 Content Plan

## Theme
The very first line of code on this 90-day journey.

---

## Hook Ideas (first 3 seconds)

- I just wrote my first line of Python…

---

## Story Arc
1. Setting up the workspace — installing Python, VS Code, creating the GitHub repo.
2. Everything feels overwhelming. So many tools, so many tabs.
3. Writing the first `print('Hello World')` and understanding variables, types, and strings.
4. The setup is done. The first commit is pushed. It's real now.
5. Tomorrow: operators, conditionals, and making decisions in code.

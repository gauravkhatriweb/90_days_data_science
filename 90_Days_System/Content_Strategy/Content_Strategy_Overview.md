# 90-Day Content Strategy Overview

## The Journey

This is a **public transformation** documented over 90 days. Not a tutorial channel. A real journey from zero Python to deployed ML applications.

## Audience

| Segment | Why They Watch |
|---|---|
| Beginners | To learn alongside someone |
| Students | For study motivation |
| Career changers | To see if it's possible |
| Build-in-public fans | For the journey narrative |

## Content Evolution

### Month 1 (Days 1-28) — The Beginner Arc
- **Vibe**: Nervous, excited, struggling, discovering
- **Topics on screen**: Python, terminal, basic projects
- **Story**: "Can I actually do this?"
- **Visual style**: Raw, real, slightly messy desk, honest

### Month 2 (Days 29-56) — The Growth Arc
- **Vibe**: Confident, focused, building real things
- **Topics on screen**: Data analysis, SQL, ML models, visualizations
- **Story**: "It's starting to click. I'm becoming a data person."
- **Visual style**: Cleaner, more structured, showing real outputs

### Month 3 (Days 57-90) — The Transformation Arc
- **Vibe**: Determined, skilled, building portfolio-worthy projects
- **Topics on screen**: Deep Learning, CNNs, deployed web apps, Kaggle
- **Story**: "I did it. From zero to Data Scientist."
- **Visual style**: Professional, showcase work, before/after comparisons

## Video Structure Template (45-60 seconds)

```
[0-3s]  Hook — one punchy line
[3-8s]  Context — what day it is, what I'm learning
[8-30s] The meat — showing the work, the struggle, the code
[30-45s] The lesson — what I learned or built
[45-55s] Tomorrow — what's next
[55-60s] Engagement — ask a question
```

## Consistency Rules

1. Upload every single day. No exceptions.
2. Film at least 3 clips daily (desk, screen, face).
3. Keep a running B-roll library (coffee, walks, sunsets).
4. Batch-edit if possible — film during the day, edit at night.
5. Imperfect and uploaded > perfect and sitting on your phone.

## Brand Voice

- **Honest**: Show struggles AND wins
- **Humble**: I'm learning, not teaching
- **Consistent**: Every day, same format, building trust
- **Curious**: "I didn't know this existed" energy
- **Growth-focused**: Every day is better than yesterday

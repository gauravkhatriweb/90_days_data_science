## 📅 How To Use This Roadmap

### Daily Workflow (Every Single Day)
1. **Open today's daily plan** → e.g., `90_Days_System/Month_1/Week_1/Daily/Day_01.md`
2. **Review Priorities** → Follow the 🔴 Must, 🟡 Should, 🟢 Optional system.
3. **Execute Learning** → Watch assigned videos (1x speed), read math chapters, and code in your `.py` file.
4. **Create Content** → Spend 30-45 minutes recording, editing, and uploading your daily reel.
5. **Push to GitHub** → Commit your work daily to maintain a 90-day streak.

### Weekly Workflow (Every End of Week)
1. **Complete the Checklist** → Verify all days were executed.
2. **Weekly Retrospective** → Fill out the `Week_XX_Summary.md` (Wins, struggles, metrics).
3. **Plan adjustments** → Move any deferred "Should" or "Optional" tasks to next week's lighter days.

### Flex Days (Days 14, 42, 70)
- **If behind**: Use these days to catch up on deferred tasks.
- **If on track**: Use for deep review, project polish, or rest.

## 🧘 Burnout Prevention Protocol

1. **Flex Days** — 3 designated flex days (Days 14, 42, 70) for catch-up or rest.
2. **Priority System** — If you finish all 🔴 Must-Do items, the day is a success.
3. **Pomodoro technique** — 50 min focus, 10 min break.
4. **Physical activity** — 30 min daily (walk, gym, anything).
5. **Emergency brake** — If energy drops severely, defer 🟡 and 🟢 items and only hit the absolute minimums.

VOICEOVER PLACEMENTS
====================

VOICEOVER 1 — During B-roll montage [0:10-0:20]
-----------------------------------------------
Use when: Showing laptop screen, typing, confused face

"Bohot saari cheezein ek saath aayi. 
Variable kya hota hai? Loop kaise chalta hai? 
List aur dictionary mein kya farq hai? 
Ek second laga jisme dimaag blank ho gaya."

Recording note: Speak softly, like thinking out loud
Distance from mic: Close, intimate
Tone: Internal monologue style

VOICEOVER 2 — During code success B-roll [0:30-0:35]
-----------------------------------------------------
Use when: Showing screen with successful code output

"Itna chota sa code tha. Bas ek for loop. 
Lekin jab output aya... lagta hai kuch 
sahi ho raha hai. Chhota step hai, lekin 
yahin se shuruwat hai."

Recording note: Warm, proud, quiet
Distance from mic: Close
Tone: Whisper of achievement

VOICEOVER 3 — Final moment [0:50-0:55]
--------------------------------------
Use when: Fade to black, "Day 1 complete" text

"89 din aur baaki hain. 
Kal nayi problems aayengi. 
Lekin aaj... aaj maine start kiya. 
Aur yeh hi sabse badi baat hai."

Recording note: Very soft, almost fading
Distance from mic: Close, then pull away slightly
Tone: Peaceful, resolved

SOUND DESIGN — Day 1
====================

KEYBOARD SOUNDS
---------------
0:08 — Soft typing under voiceover (lists topic)
0:12 — Faster typing (showing effort)
0:28 — Single key press (running code)
0:32 — Typing returns (continuing work)

MOUSE CLICKS
------------
0:10 — Click sound when switching windows
0:30 — Click to run code
0:45 — Click for git commit

COFFEE SOUNDS
-------------
0:22 — Mug pick up (subtle ceramic sound)
0:23 — Sip sound (very faint, optional)

ROOM AMBIENCE
-------------
- Constant low-level room tone under everything
- Barely audible, just removes dead silence
- Same tone throughout for consistency

PAGE TURNING
------------
0:18 — Notebook page turn (during B-roll of notes)

NOTIFICATION SOUNDS
-------------------
- DO NOT use notification sounds
- Breaks documentary feel
- Only if story requires (not today)

TERMINAL SOUNDS
---------------
0:46 — Terminal typing sound (different from regular keyboard)
0:47 — Return/enter sound (heavier than regular key)

TYPING VARIATIONS
-----------------
- Regular typing: Light, rhythmic
- Fast typing: Quicker, more intense
- Single key: Deliberate, spaced
- Terminal: Slightly different tone (can use same with pitch shift)

WHOSH/TRANSITION SOUNDS
------------------------
- DO NOT use whoosh sounds
- Keep it documentary, not vlog
- Hard cuts need no sound

CAMERA SHUTTER
--------------
- DO NOT use (not photography content)

CHAIR MOVEMENT
--------------
0:40 — Subtle chair creak when shifting position
- Very faint, adds realism

FOOTSTEPS
---------
- NOT needed today (no walking shots in main edit)

VOLUME HIERARCHY
----------------
1. Voice: -3dB peak (loudest)
2. Sound Effects: -15dB to -20dB
3. Music: -20dB to -25dB
4. Room Tone: -35dB (barely there)

RULES
-----
- Never let SFX compete with voice
- If in doubt, remove the SFX
- Less is more for documentary style
- Every sound must have purpose
- No sound "just because"
